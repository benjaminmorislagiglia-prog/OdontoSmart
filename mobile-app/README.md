OdontoSmart Mobile

OdontoSmart Mobile es la aplicación móvil que complementa al sistema OdontoSmart. Está orientada al personal de la clínica y permite consultar turnos, pacientes, historias clínicas y avisos internos. Actualmente utiliza datos simulados; la conexión con la API está pendiente.

Tecnologías utilizadas

JavaScript, React, React Native, Expo, React Navigation y AsyncStorage.

Ejecución

Abrir una terminal en la carpeta mobile-app. Si las dependencias no están instaladas, ejecutar:

npm install

Luego iniciar el proyecto:

npm start

Abrir la aplicación en el teléfono con Expo Go usando el código QR que muestra Expo.
