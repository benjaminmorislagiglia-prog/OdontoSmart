OdontoSmart Web

OdontoSmart es una aplicación web administrativa para la gestión de una clínica odontológica. Está orientada al personal administrativo, secretaría y odontólogos. El acceso para pacientes y la gestión completa de stock quedan fuera del alcance actual.

Estructura general

El sistema incluye una aplicación web, una aplicación móvil, una API REST y una base de datos SQL Server. El backend utiliza ASP.NET Core Web API y Entity Framework Core.

Tecnologías utilizadas

JavaScript, React, React DOM, Vite, Bootstrap, React Bootstrap, React Icons, React Router DOM y Axios.

Ejecución

Abrir una terminal en la carpeta frontend. Si las dependencias no están instaladas, ejecutar:

npm install

Luego iniciar la aplicación:

npm run dev

Abrir en el navegador la dirección que muestre Vite, por ejemplo http://127.0.0.1:5173.
